# JavaScript 1

JavaScript 1 is a website where you can look at different movies, search for a movie and add movies to the cart.

[View JavaScript 1](https://kimthenriksen.github.io/JS1)

## Description

I made this project for my JavaScript 1 course at Noroff.

The website gets the movies from Noroff API. You can look at the movies, search for a movie, read more about it and add it to the cart.

For Portfolio 1, I made some changes to the project based on the feedback I got.

## Features

- Movies from the Noroff API
- Search for movies
- Product details
- Add movies to cart
- Cart and checkout

## Improvements

For Portfolio 1 I made some improvements to the project:

- Added a loading message when a movie is loading
- Added an error message if movies can't be loaded
- Added a message when no movies are found when using search function
- Fixed an HTML validation error
